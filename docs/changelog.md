# Журнал доработок

Что и когда добавлено в FutureERP. Новые записи — сверху. Каждая доработка (задача TaskFlow, исправление, заметное
изменение) получает строку в день, когда попала в `main`: **модуль** — что изменилось для пользователя или разработчика,
в скобках номер задачи. Подробности — в `docs/architecture/*.md`, планах `docs/plans/` и статьях `docs/user/`.

Модули: Платформа, Проекты и задачи, CRM, Торговля, Склад, Производство, Услуги, Финансы, Транспорт, Объекты, Каталог,
Автоматизации, Настройки, Агенты и MCP, Аналитика, Справка, Деплой.

Записи до 2026-11-07 восстановлены по истории коммитов и сгруппированы по дням.

## 2026-11-14
- **Каталог** — «Все позиции» считает весь каталог, включая товары без категории (было: только с категорией, например 40 вместо 46 716); список подгружается с сервера по 100 строк при прокрутке, таблица виртуальная (в DOM только видимые строки), сортировка и фильтры — на сервере. У `DataTable` появились опции `virtual`, `manualSort`, `onEndReached`, `footer`.
- **Платформа** — живые вкладки (как KeepAlive во Vue): пять последних открытых страниц хранятся в `<Activity>` и при возврате показываются как были — прокрутка, фильтры, несохранённый ввод, без повторной загрузки; страница скрытой вкладки видит свой адрес (`useRoutes` с локацией вкладки, `app/layout/TabPages.tsx`). Маршрут с `handle.keepAlive: false` выгружается при уходе — первым прайс поставщика (запрос строк с `gcTime: 0`). `gcTime` кэша по умолчанию — 30 минут.
- **Платформа** — WebSocket гасит пачки событий: первое событие воркспейса уходит сразу, следующие в окне 100 мс — одним сообщением на сущность и тип (и при досылке по `?since`); `recordEvents(…, { notify: false })` пишет события в журнал без рассылки.
- **Цены** — «Создать товары» по прайсу поставщика тихое: события `product.created` идут в журнал для автоматизаций, но не рассылаются по WebSocket, клиенты обновляют списки по одному итоговому событию.
- **Платформа** — события realtime сбрасывают кэш пакетом (после 150 мс тишины, не реже раза в секунду): массовые операции вроде «Создать товары» по прайсу (событие на каждый товар) больше не вызывают перезапрос списков на каждое событие у каждого клиента.
- **Цены** — в прайсе поставщика нет колонки «Наш товар»: статус строки — цветная иконка с подсказкой; у найденной в подсказке наш товар, щелчок открывает его карточку справа; у конфликта щелчок — выбор из кандидатов.
- **Платформа** — прямая ссылка без `#` (`/crm/companies/…`, из уведомления, закладки, от коллеги) открывает свою страницу и вкладку, а не «Главную»: путь до создания роутера переносится в хеш, лишний путь перед хешем убирается (`apps/web/src/lib/path-to-hash.ts`).
- **Цены** — в прайсе поставщика действия строки «Выбрать/Сменить товар», «Пропустить» и «Вернуть» — иконками с подсказками вместо кнопок с текстом.
- **Платформа** — вкладки открытых страниц (как в 1С): каждый раздел и карточка открываются своей вкладкой под верхней панелью, переключаются щелчком, закрываются крестиком, средней кнопкой или из меню по правому щелчку («остальные», «справа», «все»); до 20 вкладок на воркспейс, восстанавливаются после перезагрузки (`app/layout/PageTabs.tsx`, статья `docs/user/howto/tabs.md`).

- **Производство** — «Добавить параметр» в спецификации больше не выдаёт «Проверьте значение «params.0.key»»: недозаполненный параметр живёт в черновике и сохраняется, когда название и ключ корректны; ключ следует за названием, пока его не правили руками. Поля параметра — в одну строку. Под параметрами — «Значения для расчёта»: себестоимость спецификации с формулами считается по ним, без них — подсказка вместо ошибки «Line …: fill their values in the order». Строка с формулой количества: в дереве количество посчитано и не правится, в диалоге поле «Количество» заблокировано. Диалог работы: «Часы» — числовое поле со степпером и быстрыми значениями 0,5 / 1 / 1,5 / 2; «Ставка в час» и «Фикс» — денежные поля (`MoneyInput`: только цифры и один разделитель, два знака). `NumberField` в дробном режиме показывает значение, пришедшее снаружи (бейдж, −/+), даже если раньше такое же вводили руками — раньше «2,5» после бейджа «2» и «+» оставалось «2». Часы и количество в дереве спецификации принимают запятую. «Значения для расчёта» по умолчанию: число — 1, выбор — первый вариант, дерево строк видно сразу. Секция параметров — заголовок «Параметры» с кнопкой «Добавить параметр» справа. Сохранение изменённой работы без операции каталога больше не падает с «Проверьте значение «productId»»: `PATCH /bom-lines/:id` принимает `productId: null` у работы (у остальных строк — 400). Работа в спецификации: «Формула суммы» над параметрами вместо «Фикс» (сумма работы = часы × ставка + формула, `lineFixedCost`), «Часы» узкие; под формулой работы и формулой количества материала — бейджи ключей параметров, клик вставляет ключ в позицию курсора. Пустая формула или условие при правке строки теперь очищают значение.
- **Объекты** — в смете поставщик в строке материала и субподряда: себестоимость подставляется из вида цен поставщика (`POST /estimates/supplier-prices`), правится руками; замок строки отключает автопересчёт; единая наценка сметы справа от названия — цена = себестоимость × (1 + наценка), строки без себестоимости не трогаются (миграция 0116, задача 1418). - **Платформа** — боковая карточка (`EntityDrawer`) выводится порталом в `body`: в документах (заказ на производство и др.) она больше не обрезается рамкой вкладок.
- **Производство** — в шапке спецификации размер партии, накладные, длительность и «Потребность на» — поля `NumberField` с кнопками −/+.
