# Тарифы по направлениям

## Для чего раздел

Справочник ставок по направлениям: сколько стоит перевозка по типовому маршруту. Когда в заявке на перевозку указаны «Откуда» и «Куда» (и, если нужно, тип кузова), подходящий тариф подсказывается в карточке заявки — его ставку можно подставить одной кнопкой.

## Что на экране

- **Кнопка «Новый тариф».**
- **Переключатель «Показывать архивные».**
- **Таблица** — «Название», «Направление» (откуда → куда), «Тип кузова», «Вид ставки», «Ставка», «Расстояние, км», «Статус» («В архиве» или пусто).
- **Карточка тарифа** (клик по строке): «Название», «Откуда», «Куда», «Тип кузова», «Вид ставки» («За рейс», «За километр», «За тонну»), «Ставка», «Расстояние, км», «Комментарий». Кнопка «В архив» / «Восстановить».

## Типовые действия

### Добавить тариф

1. Нажмите «Новый тариф».
2. Укажите «Название», «Откуда» и «Куда» (как они должны совпасть с полями заявки, чтобы тариф подсказался), при необходимости «Тип кузова».
3. Выберите «Вид ставки» и укажите «Ставку»; для ставки «За километр» укажите «Расстояние, км».
4. Нажмите «Сохранить».

Совпадение «Откуда»/«Куда» и типа кузова в подсказке — по точному тексту полей. Если тип кузова в тарифе не задан, тариф подходит для любого типа кузова.

### Изменить или убрать тариф

Откройте тариф из таблицы, измените поля и нажмите «Сохранить». Если тариф больше не актуален, но нужен для истории, нажмите «В архив» — он перестаёт подсказываться в заявках, но остаётся в списке при включённом переключателе «Показывать архивные». «Восстановить» возвращает его в работу.

## Права

Читают все, создают и меняют участники с правом редактирования, гость только смотрит. Раздел входит в модуль «Транспорт».

## Частые ошибки

- **Тариф не подсказывается в заявке.** Проверьте, что «Откуда»/«Куда» в заявке совпадают с тарифом по тексту, а тип кузова совпадает или не задан в тарифе. Архивный тариф не подсказывается.
- **Тариф не найден в списке.** Включите переключатель «Показывать архивные» — возможно, он в архиве.
