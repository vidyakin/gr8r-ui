# КЭДО — кадровый электронный документооборот: справка

Справка из разговора 2026-10-30, по памяти модели, без источников. Перед проектированием модуля сверить с текущей редакцией ст. 22.1–22.3 ТК РФ
и с юристом: правила меняли несколько раз.

## Подписи (ст. 22.1–22.3 ТК РФ)
- **Работодатель** — УКЭП. Директору выдаёт УЦ ФНС бесплатно; кадровик подписывает своей личной УКЭП с машиночитаемой доверенностью (МЧД).
  Средство подписи — сертифицированное ФСБ (КриптоПро CSP).
- **Сотрудник** — одно из трёх:
  1. своя УКЭП;
  2. УНЭП, выпущенная информационной системой работодателя или УЦ, только после идентификации через ЕСИА (Госуслуги);
  3. ПЭП — только при ведении КЭДО через госплатформу «Работа в России» (ЕЦП).
- **Госключ** — бесплатное приложение Госуслуг, физлицо подписывает УНЭП/УКЭП. Многие сервисы КЭДО подключают его вместо выпуска подписей самим.

## Кроме подписи
- Письменное согласие каждого сотрудника на электронный документооборот, с правом отказа.
- Хранение 50/75 лет с проверяемой подписью после истечения сертификатов: CAdES-XLT1/усовершенствованная подпись — метка времени (TSP)
  и статус сертификата (OCSP) на момент подписания. Выдача документа с подписью сотруднику по запросу.
- 152-ФЗ: базы в РФ; облачный сервис с данными чужих сотрудников — ИСПДн: модель угроз, уровень защищённости, меры ФСТЭК. Для SaaS — самая тяжёлая часть.
- Не всё электронное (бумажные трудовые книжки и др.). Сведения в СФР (ЕФС-1, электронная трудовая) — отдельно, через оператора отчётности.

## На нашем стеке
- **Подпись в браузере**: токен пользователя через КриптоПро ЭЦП Browser plug-in (`cadesplugin`), сервер хранит PDF и открепленную `.sig`.
  КриптоПро на сервере не нужен. Самый реальный путь для подписи работодателя.
- **Подпись на сервере**: КриптоПро CSP для Linux в контейнере воркера, лицензия на сервер. Нужна для автоматической подписи организации или
  своего выпуска УНЭП сотрудникам (по сути работа УЦ — не браться).
- **Проверка подписи**: в Node нет ГОСТ; OpenSSL без gost-engine тоже, а gost-engine не сертифицирован. Проверять КриптоПро на сервере или сервисом оператора.
- **Своё**: маршруты подписания, шаблоны документов (печатные формы и PDF уже есть), ознакомление, статусы, архив, уведомления.

## Рекомендация
Как, вероятно, 1С:КЭДО: не строить цепочку подписи самим, а подключить оператора КЭДО или УЦ по API — он выпускает подписи сотрудникам
(или Госключ), ставит метки времени и хранит юридически значимый архив; у нас — интерфейс поверх кадровых данных и подпись работодателя через
плагин в браузере. Открыть: сравнение операторов КЭДО (API, Госключ, цена) с актуальными источниками.
