# Рейтинг поставщиков

Раздел показывает рейтинг поставщиков за выбранный период (по умолчанию 12 месяцев), рассчитанный по проведённым документам.

## Показатели

- **Сроки** — доля заказов поставщику, по которым поступление пришло не позже плановой даты.
- **Полнота** — доля поступившего количества к заказанному.
- **Качество** — с учётом отклонённых партий и возвратов поставщику.

Итоговый балл 0–100 и уровень A/B/C/D. Настройки весов и политика при уровне D — в настройках.
