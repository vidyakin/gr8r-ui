# Защита входа

## Для чего раздел

Двухфакторная аутентификация защищает аккаунт, если кто-то узнает ваш пароль. Воркспейс может требовать второй фактор от участников и разрешать доступ только с указанных IP-адресов.

## Что на экране

- **Настройки → Безопасность → Двухфакторная аутентификация** показывает состояние защиты и количество оставшихся резервных кодов.
- **Настройки → Безопасность → Безопасность воркспейса** содержит переключатель **Обязательная 2FA для всех участников**, белый список IP и журнал входов. В журнале видны время попытки, электронная почта, IP, способ входа, результат и сведения о браузере или клиенте.

## Типовые действия

### Подключить второй фактор

1. Нажмите **Подключить двухфакторную аутентификацию**. Отсканируйте QR-код приложением для аутентификации или введите в него ключ вручную.
2. Введите шестизначный код из приложения и нажмите **Подтвердить и включить**. Другие сеансы аккаунта завершатся.
3. Сохраните десять резервных кодов в надёжном месте и нажмите **Я сохранил коды**. Коды показываются один раз. Каждый код работает только при одном входе.

При следующем входе введите пароль, затем код из приложения или резервный код формата `XXXX-XXXX`. Для отключения защиты нажмите **Отключить двухфакторную аутентификацию** и подтвердите действие текущим паролем или кодом из приложения.

### Защитить воркспейс

1. Включите **Обязательная 2FA для всех участников**, чтобы сотрудники настраивали второй фактор перед работой в воркспейсе.
2. Чтобы ограничить доступ по сети, внесите IP-адреса или диапазоны CIDR в белый список, по одному на строку. Поддерживаются IPv4 и IPv6, например `95.25.126.187`, `192.168.1.0/24` и `2001:db8::/32`.
3. Сверьте список с полем **Ваш текущий IP**. Нажмите **Сохранить настройки безопасности**. Пустой список разрешает все адреса.

## Права

Двухфакторную аутентификацию можно включить в своём аккаунте. Общий демо-аккаунт не поддерживает подключение 2FA. Настройки воркспейса и его журнал входов доступны владельцу и администраторам. Требование 2FA также применяется к токенам доступа. Служебные аккаунты, у которых нет входа с паролем, теряют доступ к воркспейсу при включении этого правила.

## Частые ошибки

- **Требуется двухфакторная аутентификация.** Откройте предложенный экран настройки и сохраните резервные коды. После этого вернитесь в воркспейс.
- **Код отклонён.** Дождитесь следующего кода в приложении и проверьте, что на устройстве включена автоматическая настройка времени. Если устройство недоступно, используйте свободный резервный код.
- **IP-адрес заблокирован.** Подключитесь через разрешённую сеть или обратитесь к администратору воркспейса.
- **Список не сохраняется.** В непустом списке должен быть ваш текущий IP-адрес или диапазон, который его включает.
