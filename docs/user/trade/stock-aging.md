# Склад — старение запасов

## Для чего раздел

Показывает, сколько товара лежит на складе и как давно он поступил. Остаток каждого товара на каждом складе разложен по возрасту поступления: 0–30, 31–60, 61–90, 91–180 и больше 180 дней. Так видно залежавшийся товар, который стоит продать со скидкой или списать.

## Что на экране

- **Плитки сверху** — итог по каждому возрасту.
- **Отборы**: «На дату» (по умолчанию сегодня; остаток и возраст считаются на эту дату), склад, категория товара (вместе с вложенными), поиск по товару или артикулу.
- **Таблица** — товар, артикул, склад, остаток по пяти возрастам и итого. Колонки можно скрывать и сортировать.
- **Кнопка «Количество» / «Сумма»** переключает таблицу между штуками и деньгами. Она есть только у владельцев и администраторов: остальные участники видят количество без стоимости.

## Как считается возраст

- Товар с партионным учётом: возраст партии — со дня её первого прихода на склад.
- Остальной товар: расходы списывают самые старые приходы (FIFO), на складе остаются самые свежие поступления.
- Сумма — по цене прихода каждой части остатка, поэтому может отличаться от стоимости по средней в разделе «Склад — остатки».

## Частые ошибки

- **Остаток не совпадает с «Остатками».** Отчёт считает остаток на выбранную дату; проверьте поле «На дату».
- **Нет кнопки «Сумма».** Стоимость видят только владельцы и администраторы.
