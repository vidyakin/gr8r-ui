# Объектный учёт: стройка, электромонтаж, EPC — решения (2026-11-06)

Задача TaskFlow 1267, сессия 57. Источники: задача 1259 (блок «Строительство»), предварительный план
[модуля электромонтажных объектов](../superpowers/plans/2026-10-24-electrical-contracting-module.md), сравнение с ERPNext for EPC.
Архитектура — [docs/architecture/construction.md](../architecture/construction.md).

## Ответы пользователя

| Вопрос | Решение |
|---|---|
| Сущность объекта | **Новая сущность `objects`**. Инвестпроекты остаются про окупаемость, проекты задач — про задачи |
| Под кого первая версия | **Ядро + отраслевые слои**: универсальное ядро (объект, смета-бюджет, факт, вехи, прогноз), слой «полевые работы» (табель прораба, щиты), слой «стройка РФ» (КС-2/КС-3, субподряд). Порядок: ядро → табель → акты и субподряд |
| Состав первой версии | Объект, табель прораба, смета и план-факт, прогноз прибыли и бюджет, акты и субподряд |
| Примеры документов пилота | Нет — проектируем по типовым формам, импорт Excel с сопоставлением колонок |
| Выручка | **Все три способа** на уровне объекта: по актам фактических объёмов (КС-2), фикс по этапам (вехи), по часам |
| Стоимость часа рабочего | **Из зарплаты**: часовая стоимость из оклада сотрудника (оклад / норма часов месяца по графику) или из почасовой ставки, плюс взносы `payroll_insurance_rate`; снимок стоимости фиксируется при подтверждении табеля |
| Ввод времени | **Итог часов за смену**: бригада пакетом (например, по 8 ч) с исключениями, распределение по позициям сметы; бейдж — быстрый выбор работника |
| Затраты в прогнозе | **Прямые + % накладных**: материалы, труд, субподряд, прочие прямые; накладные — процент объекта (по умолчанию из настройки воркспейса, можно 0) |
| Остаток для прогноза | **По темпу + правка**: по фактической выработке позиции сметы; прораб/руководитель может заменить оценку с причиной |
| Материалы | **Склад объекта**: передача на объект — перемещение (ещё не затрата); затрата — списание в работы с аналитикой объекта; возврат — обратное перемещение |
| Версии сметы | **Согласование + допработы**: черновик → согласована (снимок цен и норм, база план-факта); допработы — отдельные дополнения со своим статусом. Полной истории версий нет |

## Решения по умолчанию (не спрашивались, можно пересмотреть)

- Нормативные базы ГЭСН/ФЕР, журнал КС-6, спецодежда и инструмент — вне первой версии.
- Сравнение затрат и выручки — **без НДС**; суммы сметы хранятся без НДС, ставка НДС — у позиции для печати и счетов.
- Внутренние ставки, себестоимость и прогноз видят **owner и admin** (`canSeeCost`); прораб видит объёмы и часы, но не деньги.
- Табель прораба в первой версии — **онлайн**; офлайн-черновик на телефоне — после пилота.
- Работник без входа в систему — участник воркспейса без `user_id` (`members.user_id` уже допускает null).
- Один объект — один основной заказчик; несколько договоров на объекте допустимы (ссылки на `contracts`).
- Щит из производства попадает в затраты объекта **один раз** — себестоимостью выпуска при списании на объект; комплектующие и труд сборки не добавляются повторно.
