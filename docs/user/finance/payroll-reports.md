# Отчёты по зарплате и расчётный листок

## Для чего раздел

«Отчёты по зарплате» показывают расчёты с персоналом и свод начислений. «Мой расчётный листок» — личный экран сотрудника: что ему начислено, удержано и выплачено за месяц.

## Что на экране

### Отчёты по зарплате

Поля «С» и «По» и две вкладки:

- **«Расчёты с персоналом»** — по каждому сотруднику: «Долг на начало», «Начислено», «Удержано», «Выплачено», «Долг на конец».
- **«Свод начислений»** — начисления «По видам» и «По участкам» (в том числе «Без участка»), с НДФЛ и взносами.

### Мой расчётный листок

Выбор месяца («Период»). Таблица начислений и удержаний за месяц, итоги «Начислено», «Удержано» и «К выплате», «Долг на конец месяца». Кнопка «Печать» открывает печатную форму листка. Если проведённых начислений нет, показано «За этот месяц нет проведённых начислений».

## Типовые действия

### Узнать задолженность по зарплате на конец месяца

«Отчёты по зарплате» → «С» и «По» = границы месяца → вкладка «Расчёты с персоналом» → итоговая строка «Долг на конец».

### Посмотреть свой расчётный листок

Откройте «Мой расчётный листок», выберите месяц. Для печати нажмите «Печать».

## Права

- Отчёты по зарплате видят только владелец и администраторы.
- Расчётный листок доступен каждому сотруднику, но он видит только свой.
- Раздел входит в модуль «Зарплата».

## Частые ошибки

- **В листке пусто.** За месяц нет проведённых начислений по вам. Подождите, пока бухгалтер проведёт начисление.
- **Сообщение «Только для администраторов» в отчётах.** Суммы зарплаты видят только владелец и администраторы; свой листок — в «Мой расчётный листок».
- **Долг в отчёте не совпадает с выплатами.** Учитываются только проведённые начисления и проведённые выплаты.
