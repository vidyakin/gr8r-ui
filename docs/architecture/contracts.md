# Шаблоны договоров: назначения, параметры сторон, печать и PDF (задача 1194)

Расширение шаблонов КП (`quotes.md`, задача 1190): тот же справочник `doc_templates`, тот же редактор и та же разметка.
Решения — `docs/plans/2026-10-29-docflow.md`, раздел «Задача 1194».

Код: рендер `packages/shared/src/print/contract.ts` (общий разбор разметки — `renderMarkup` в `print/quote.ts`), данные и страница
`packages/db/src/contract-print.ts`, составные формы в `renderDocumentHtml` (`money-print.ts`), API `apps/api/src/routes/contracts.ts`
(`/contracts/:id/print`, `/pdf`) и `doc-templates.ts`, воркер `contract.pdf` (`apps/worker/src/handlers.ts`), интерфейс
`docs/QuoteTemplatesPage.tsx`, `docs/ContractPrintPage.tsx`, диалог договора в `docs/contracts.tsx`, меню «Печать» в `DocumentPage.tsx`.
Миграция `0063_contract_templates.sql`. Тесты: `packages/shared/test/contract.test.ts`, `apps/api/test/contract-templates.test.ts`.

## Назначения шаблонов
`doc_templates.purpose` (как в справочнике 1С): `quote`, `contract` («Договор»), `contract_order` («Договор + Заказ покупателя»),
`contract_invoice` («Договор + Счёт»), `contract_work_order` («Договор + Заказ-наряд»). Назначение задаётся при создании и дальше не
меняется (`docTemplateUpdate` его не принимает). Список `/doc-templates?purpose=…`; в редакторе — фильтр по назначению, новый шаблон
создаётся с выбранным назначением и его стандартным текстом.

## Параметры договора и сторон
Хранятся в `contracts`: номер, дата, срок (`valid_from`/`valid_to`), вид, отсрочка (`payment_days`), примечание — и новые колонки для печати:
`org_signer_basis` (основание полномочий нашего руководителя, пусто — «Устава»), `party_signer_name`, `party_signer_title`,
`party_signer_basis` (подписант контрагента). Подписант контрагента живёт **в договоре, а не в контрагенте**: доверенности и приказы
бывают разные на разные договоры. Наш руководитель — из организации (`directorName`, `directorTitle`).
Параметры — `CONTRACT_TEMPLATE_PARAMS`: «Номер договора», «Дата договора», «Срок действия», «Начало/Окончание срока», «Вид договора»,
«Отсрочка оплаты», «Организация», «ИНН/КПП/ОГРН/Адрес/Банк организации», «Руководитель организации», «Организация в лице»
(«ООО …, в лице … действующего на основании …»), то же для контрагента, и параметры документа: «Номер/Дата документа», «Сумма»,
«Сумма прописью», «НДС», «Оплатить до», «Комментарий документа». Блоки: `{{Товары}}` (таблица документа), `{{Подписи сторон}}`
(реквизиты и подписи двух сторон, печать и подпись организации). Правила разметки — как у КП: экранирование, незнакомый параметр остаётся
текстом, строка со всеми пустыми параметрами не печатается (поэтому у «чистого» договора строки документа пропадают сами).

## Печать
- **Договор без документа.** Карточка договора (клик по строке в «Договорах») → «Печать»: стандартный договор или шаблоны с
  `purpose = contract`. `GET /contracts/:id/print?template=` — HTML, `POST /contracts/:id/pdf { templateId? }` — задача `contract.pdf`,
  файл в новой таблице `contract_files` (bytea, статус `pending → ready | failed`), `GET /contracts/:id/pdf/:fileId[?download=1]`.
  Отдельная таблица, а не `document_files`, потому что документа нет; хранилище PDF печатных форм документов (`document_files`) не затронуто.
- **Договор + документ.** Формы `contract_order`, `contract_invoice`, `contract_work_order` (в `PRINT_FORMS`, но не в `DOCUMENT_META.forms`):
  доступны заказу покупателя, счёту и заказ-наряду соответственно (`CONTRACT_FORM_BY_TYPE`, `formAllowedFor`). Договор — `documents.contract_id`;
  без договора форма недоступна (422 `contract_required`, пункта нет в меню «Печать»). Предпросмотр
  `GET /documents/:id/print/contract_order?template=`, PDF `POST /documents/:id/pdf { form, templateId }` — тем же путём, что КП
  (`document_files.template_id`, `usesTemplate(form)`). Шаблон другого назначения или чужой «только автор» — 404.
- **Встроенные шаблоны** — по одному на назначение (`DEFAULT_CONTRACT_TEMPLATES`): «Договор поставки» (`contract`), «+ Заказ покупателя»,
  «+ Счёт» и «Договор оказания услуг» (`contract_work_order`). Без выбора шаблона печатается встроенный; с него же начинается новый шаблон.
