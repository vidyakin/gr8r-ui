# Складские документы

## Для чего раздел

Внутренние документы склада — те, где нет покупателя или поставщика: перемещение товара между складами (в том числе «в пути»), передача в эксплуатацию, списание, оприходование, ввод начальных остатков и инвентаризация. Они двигают остатки и себестоимость, но не выручку.

## Что на экране

- **Вкладки по типам**: «Все», «Перемещение товаров», «Списание товаров», «Оприходование товаров», «Начальные остатки товаров», «Инвентаризация».
- **Таблица** — номер, тип, дата, «Склад-отправитель», «Склад-получатель», организация, статус и «Себестоимость» документа по средней цене. Себестоимость видят только владельцы и администраторы. Поиск — по номеру или комментарию.
- **Кнопка «Новый документ»** — меню с типами.
- **Форма документа** — как у других документов: шапка, таблица товаров, итоги и комментарий внизу. Состав шапки зависит от типа:
  - перемещение — «Склад-отправитель», «Склад-получатель», «Вид перемещения»;
  - списание — склад, «Статья затрат» (обязательна), «Участок»;
  - оприходование — склад, «Статья доходов» (обязательна);
  - начальные остатки — только склад (статьи нет);
  - инвентаризация — склад.
  Контрагента у этих документов нет, НДС в строках не учитывается.

## Типовые действия

### Переместить товар между складами

1. «Новый документ» → «Перемещение товаров».
2. Выберите склад-отправитель и склад-получатель (они должны различаться), «Вид перемещения» — «Прямое перемещение».
3. Добавьте товары и количество, нажмите «Провести». Товар сразу уходит с одного склада и приходит на другой по своей себестоимости.

### Перемещение «в пути»

Подходит, когда товар едет и ещё не принят получателем.

1. В поле «Вид перемещения» выберите «В пути» и проведите документ — товар уходит со склада-отправителя и числится «в пути» (в шапке бейдж состояния «отправлено»).
2. Когда товар доехал, откройте документ и в колонке «Принято» проверьте принятое количество (по умолчанию — отправленное, меньше можно, больше нельзя).
3. Нажмите «Принять» — товар появится на складе-получателе; непринятая часть остаётся «в пути». Кнопка «Отменить приёмку» возвращает документ в «отправлено».

### Передать в эксплуатацию и вернуть

1. Перемещение с видом «В эксплуатацию»: выберите склад, «Получатель» (сотрудник или участок), статью затрат, добавьте товары.
2. После проведения товар списывается со склада на статью затрат и учитывается в разделе «В эксплуатации» — у кого и сколько (см. [В эксплуатации](in-use.md)).
3. Для возврата создайте перемещение «Из эксплуатации», выберите получателя и склад — количество у получателя уменьшится.

### Списать товар

1. «Новый документ» → «Списание товаров».
2. Выберите склад и «Статью затрат» (например, «Брак», «Порча», «Недостача»); для расходов участка укажите «Участок» — стоимость станет косвенными затратами участка.
3. Добавьте товары и проведите документ. Товар списывается по средней себестоимости.

### Оприходовать товар

1. «Новый документ» → «Оприходование товаров».
2. Выберите склад и «Статью доходов» (например, «Излишки»).
3. Добавьте товары. Цена в строке — себестоимость единицы прихода: по умолчанию средняя по складу, иначе цена последнего поступления или закупочная цена. Менять её могут только владельцы и администраторы.
4. Проведите документ.

### Внести начальные остатки

Документ нужен один раз при запуске, чтобы ввести остатки товаров на дату начала учёта. В отличие от оприходования, он не требует статьи доходов и не считается доходом.

1. «Новый документ» → «Начальные остатки товаров».
2. Выберите склад. Для каждого склада нужен свой документ.
3. Поставьте дату — день перед началом учёта.
4. Добавьте товары и количество. «Цена» в строке — себестоимость единицы; менять её могут только владельцы и администраторы, остальным подставляется средняя.
5. Нажмите «Провести»: количество и «Стоимость остатков» появятся в «Торговля» → «Остатки». Печатной формы у документа нет.

Отмена проведения снимает остатки, если по ним не было движений. Документ с датой в закрытом периоде не проводится и не отменяется.

### Провести инвентаризацию

1. «Новый документ» → «Инвентаризация», выберите склад.
2. Нажмите «Заполнить по остаткам» — в таблицу попадут все позиции склада с колонкой «Учёт» (по программе).
3. Введите в колонке «Кол-во» фактическое количество; колонка «Откл.» покажет разницу (минус — недостача, плюс — излишек). Внизу — число недостач и излишков.
4. Проведите документ. Остатки при этом **не меняются**.
5. Чтобы привести остатки в порядок, откройте проведённую инвентаризацию и нажмите «Создать на основании»: «Списание товаров» для недостач (статья «Недостача») и «Оприходование товаров» для излишков (статья «Излишки»). Документы заполнятся строго по разнице; сверх разницы оформить нельзя.

Для товаров с серийными номерами в строке инвентаризации указываются найденные номера.

### Напечатать документ

Кнопка «Печать» открывает предпросмотр: инвентаризационная опись (ИНВ-3), акт о списании (ТОРГ-16), накладная на внутреннее перемещение (ТОРГ-13). Оприходование и начальные остатки отдельной печатной формы не имеют. Из предпросмотра можно распечатать форму или скачать PDF.

### Отменить документ

Чтобы отменить черновик, в меню «Ещё» выберите «Отменить документ» и введите причину — она сохраняется и показывается над шапкой. «Отменить проведение» возвращает остатки. Нельзя отменить документ, если по нему созданы проведённые документы (например, списание по инвентаризации), или если позднейшие операции уже используют его приход.

## Права

- Смотреть документы могут все участники, создавать и проводить — участники с правом записи.
- Стоимость (себестоимость документа, средняя цена, цена оприходования) видят владельцы и администраторы. Участники видят количество, но не стоимость; цену оприходования им подставляет система.
- Статьи затрат и доходов ведут администраторы в «Настройки» → «Статьи затрат».
- Склады и правило отрицательного остатка настраиваются в «Настройки» → «Склады» (администраторы).

## Частые ошибки

- **Не хватает остатка при проведении.** Проведение отклоняется, ничего не записывается. Уменьшите количество или оформите приход. Администратор может разрешить отрицательный остаток в «Настройки» → «Склады».
- **Нельзя провести без статьи.** Для списания выберите статью затрат, для оприходования — статью доходов; вид статьи должен соответствовать документу. У начальных остатков статьи нет.
- **«Период закрыт — документ нельзя изменить».** Дата документа попала в закрытый месяц: выберите более позднюю.
- **Склад-получатель совпадает с отправителем.** Выберите другой склад.
- **Нельзя отменить передачу в эксплуатацию.** Если после отмены остаток у получателя стал бы отрицательным — сначала отмените возврат.
- **Нужны серийные номера.** Для товаров с учётом по номерам введите номера по количеству — [Серийные номера](serials.md).
