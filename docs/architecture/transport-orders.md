# Заявки на перевозку и маржа рейса

Задача 1223 (TaskFlow, сессия 50); решения — `docs/plans/2026-10-30-tms.md`, пункт 8. Модуль тарифов `transport` ([licensing.md](licensing.md)), рейсы — [trips.md](trips.md), автопарк — [fleet.md](fleet.md).

Код: схема `packages/db/src/schema/transport-orders.ts`, миграция `0080_transport_orders`, сервис `packages/db/src/transport-orders.ts`; расчёты `packages/shared/src/transport-orders.ts`, печать `print/carrier-contract.ts`; API `apps/api/src/routes/transport-orders.ts` (корневой путь `/transport-orders`); экраны `apps/web/src/app/transport-orders/*`, блок рейса `TripEconomics.tsx`. ## Данные (таблицы под RLS, ссылки составные `(workspace_id, id)`)
- `transport_rate_schedules` — тариф направления: откуда, куда, тип кузова, вид ставки `flat | per_km | per_ton`, ставка, расстояние.
- `transport_orders` — заявка: номер `ЗП-ГГГГ-NNNNN`, заказчик, организация, маршрут, груз, ставка и сумма, статус, `trip_id`, `invoice_document_id`, `act_document_id`.
- `transport_order_points` — точки заявки `load | unload` по порядку.
- `fleet_trip_carriers` — наёмный перевозчик рейса, одна запись на рейс: компания, ставка, реквизиты машины и водителя, договор.
- `fleet_trip_costs` — прочие затраты рейса статьями затрат (платные дороги, амортизация ставкой на км).

## Правила
- **Статусы.** `draft → confirmed → in_progress → done`, отмена из любого незавершённого. Удаляется только черновик. Интерфейс правит только черновик.
- **Рейс.** Рейсу нужны машина и водитель, поэтому он создаётся в разделе рейсов, а подтверждённая заявка закрепляется за ним (409 `transport_order_not_confirmed`). Точки заявки становятся точками рейса с `source_kind = 'transport_order'`; вес и объём ставятся на первую погрузку и последнюю выгрузку, чтобы контроль вместимости считал груз один раз. При отмене заявки её незавершённые точки уходят из открытого рейса.
- **Счёт и акт.** Обычные документы на услугу, выбранную пользователем, цена равна сумме заявки, по одному на заявку (409 `already_billed`).
- **Сумма заявки.** Считается по ставке, если не задана вручную; правка других полей ручную сумму не сбрасывает.
- **Маржа рейса** (`GET /transport-orders/trips/:id/margin`, только администраторы): доход неотменённых заявок рейса минус топливо по путевым листам этого рейса, ставка перевозчику и прочие затраты. Ремонты и штрафы к рейсу не относятся: они остаются в затратах автопарка за период. У рейса с наёмным перевозчиком топлива нет и считается маржа экспедитора.
- **Договор-заявка** собирается на запрос по данным рейса, отдельного реестра и нумерации нет. Требует назначенного перевозчика (422 `carrier_not_assigned`).

## Ограничения
- Рейс требует свою машину и водителя и при наёмном перевозчике: `vehicle_id` и `driver_member_id` обязательны, занятость по ним учитывается.
- Правка заявки после закрепления не меняет точки рейса.
- Амортизация ставкой на км вводится прочей затратой вручную.
