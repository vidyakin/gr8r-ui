# Отраслевые опции воркспейса

Задача 1258. Отраслевая опция — **бесплатная настройка вида воркспейса**, а не модуль тарифа: `packages/shared/src/licensing.ts`
её не знает, `requireModule` и `useModuleReady` на неё не смотрят, API-пути не блокируются. Выключение опции только прячет
разделы, поля и колонки интерфейса; **данные, правила проведения и ответы API не меняются**, ничего не удаляется.
Не путать с [модулями и тарифами](licensing.md): модуль включает данные и права, опция — вид.

## Список и хранение

- Список опций — константа в `@gr8r/shared` (`packages/shared/src/industry.ts`): `INDUSTRY_OPTIONS = ['food','construction']`,
  тип `IndustryOption`, проверка `industryOptionsSchema` (zod), помощники `hasIndustry(options, option)`, `resolveIndustryOptions(raw)`
  (неизвестное отбрасывает, повторы схлопывает).
- Хранение — `workspaces.industry_options text[] NOT NULL DEFAULT '{}'` (`packages/db/src/schema/core.ts`) с CHECK
  `workspaces_industry_options_chk`: элементы только из списка. Пустой набор — всё выключено.
- Миграция `0092_industry_options` (SQL написан вручную): существующие воркспейсы получают `{food,construction}`, чтобы их экраны
  не изменились; новые воркспейсы (`signup`, `createTenant`/`initWorkspace`) создаются с `'{}'`; демо-сид
  (`packages/db/src/seed.ts`) включает все опции.
- Читают все участники: `GET /workspaces` (поле `industryOptions` каждого воркспейса) и `GET /workspaces/:id` (вся строка).
  Меняют owner и admin: `PATCH /workspaces/:id { industryOptions }` — набор целиком, участнику 403, значение не из списка 400.
  Запись идёт событием `workspace.updated` в той же транзакции; realtime сбрасывает кэш `['session']`, поэтому другие вкладки
  видят изменение сразу.

## Что прячет `food` (пищевое производство)

| Где | Что скрыто |
|---|---|
| Меню, палитра, вторая панель, `SectionGuard` | раздел «Партии» (`SECTIONS.batches`, путь `/batches`) |
| Карточка товара (`apps/web/src/app/catalog/product-ui.tsx`) | «Партионный учёт» (`trackBatches`) и «Срок годности» (`shelfLifeDays`) |
| Строки документа (`apps/web/src/app/docs/DocumentPage.tsx`, `batch-ui.tsx`) | кнопка партии прихода: номер партии, дата выработки, «годен до» |
| Настройки → Склады, форма склада (`apps/web/src/app/settings/documents.tsx`) | вид склада «Карантин» в выборе |

Правила-исключения (без них ломается проведение):

- Поле партии в строке документа остаётся, если **хотя бы у одного товара документа** включён партионный учёт: сервер отклоняет
  приход такого товара без номера партии.
- Переключатель «Партионный учёт» в карточке товара остаётся, если у товара он уже включён — иначе его нельзя было бы выключить.
- Существующий карантинный склад показывается как есть (бейдж «Карантин»), из выбора пропадает только возможность создать новый.

ОТК выпуска (справочник «Причины брака», вкладка «ОТК», переделка, отчёт «Брак и ОТК») остаётся всем: это не отраслевая опция.

## `construction` (строительство и монтаж)

Пока ничего не прячет — есть только флаг и механизм, для будущей объектной модели.

## Правило для новой отраслевой фичи

1. Нужна новая отрасль — добавь её в `INDUSTRY_OPTIONS` (`@gr8r/shared`) **и** в CHECK-условие `workspaces_industry_options_chk`
   новой миграцией; существующему набору — значение по умолчанию по решению задачи.
2. Фича регистрирует себя за опцией: раздел меню — строка в `INDUSTRY_OF_SECTION` (`apps/web/src/app/industry/data.ts`),
   поля и колонки — проверка `useIndustry(option)` рядом с ними.
3. Ничего не блокируется на сервере: API, проведение, задачи воркера и данные работают так же при выключенной опции.
   Если без поля документ нельзя провести — поле показывается (как с партиями выше).

## Интерфейс

- `useIndustry(option)` и `useEnabledIndustries()` — `apps/web/src/app/industry/data.ts`; набор берётся из сессии (`GET /workspaces`),
  пока он грузится, всё считается включённым (меню не мигает).
- Скрытие разделов — тот же механизм, что у должностей и модулей: `useSectionAccess()` (`apps/web/src/app/positions/access.tsx`)
  отвечает «должности И модули И отраслевые опции»; по нему работают меню, вторая панель, палитра и `SectionGuard`.
  Экран, скрытый опцией, показывает «Раздел скрыт» с подсказкой, где включить.
- Включение — Настройки → «Воркспейс» → блок «Отрасль» (тумблеры «Пищевое производство…» и «Строительство и монтаж…»),
  доступно owner и admin. Тексты — ключи `settings.workspace.industry.*` в словарях `en` и `ru`.

Тесты: `apps/api/test/industry-options.test.ts` (owner/admin 200, участник 403, чужое значение 400, новый воркспейс без опций).
