# Скриншоты для страниц модулей лендинга (2026-11-16)

Страницы `/modules/<id>/` (`apps/landing/src/pages/modules/[id].astro`, тексты — `modulePages.<id>` в `src/i18n/module-pages.ts`). Пока файла нет, на странице рисуется заглушка с подписью экрана; положить файл в `apps/landing/public/modules/<id>/` — и он подхватится при следующей сборке (проверка через `fs`).

Как снимать: демо-стенд (`demo@future-erp.dev`), русский язык, светлая тема, окно 1440 × 900, формат JPG (качество около 85), пропорции 16:10 (1280 × 800 после обрезки), без персональных данных. Номер файла — порядок блока на странице. Путь указан для приложения вида `/#/…`.

`hero.jpg` нужен только модулям без «записи» (в `src/demo/registry.ts` сцены нет): sales, logistics, automations, payroll. Когда сцена появится в реестре, `hero.jpg` не используется.
