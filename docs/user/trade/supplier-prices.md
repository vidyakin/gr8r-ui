# Загрузка прайсов поставщиков

## Для чего раздел

Поставщик присылает прайс в файле, а цены нужно разложить по нашим товарам. Вкладка «Прайсы» в карточке контрагента читает файл по настроенному формату, сопоставляет строки с нашей номенклатурой по артикулу поставщика и записывает цены в вид цен этого поставщика.

## Что на экране

Вкладка «Прайсы» открывается в карточке контрагента (раздел CRM «Компании»). Она видна владельцу и администраторам: цены поставщиков скрыты от участников.

- **Прайсы поставщика** — список загруженных файлов: название, дата действия, статус («Черновик» или «Применён»), счётчики «Найдено», «Не найдено», «Конфликт». Название открывает экран прайса, значок со стрелкой скачивает исходный файл, корзина удаляет черновик. Кнопка «Загрузить прайс» открывает окно загрузки.
- **Форматы файлов** — сохранённые настройки: с какой строки идут данные и в каких колонках артикул, наименование, цена и единица. Кнопка «Настроить формат» создаёт формат, карандаш меняет, корзина удаляет.

### Экран прайса

Открывается по названию прайса. Вверху — дата действия, признак «Цены с НДС», исходный файл и кнопки «Найти по названиям», «Создать товары» и «Применить». Ниже таблица строк файла: номер строки, артикул, наименование, единица, цена, наш товар и статус. Фильтр над таблицей показывает число строк в каждом статусе:

- **Найдено** — по артикулу поставщика нашёлся ровно один наш товар.
- **Не найдено** — артикула у нас нет.
- **Конфликт** — артикул совпал с несколькими товарами: выберите нужный в списке кандидатов.
- **Пропущено** — строка не попадёт в применение (нет цены, пропущена вручную или у товара не задана ставка НДС).

## Типовые действия

### Настроить формат файла

1. На вкладке «Прайсы» нажмите «Настроить формат».
2. Выберите файл-образец (XLSX или CSV) — появятся его первые строки.
3. Нажмите на строку, с которой начинаются данные, — она станет «Первой строкой данных».
4. Над колонками выберите, что в них: «Артикул», «Наименование», «Цена», «Ед.». Артикул и цена обязательны.
5. Введите название формата и нажмите «Сохранить формат».

### Загрузить прайс

1. Нажмите «Загрузить прайс».
2. Выберите формат файла, сам файл (до 10 МБ), при желании название. Укажите дату действия цен и включите «Цены с НДС», если в файле цены с НДС.
3. Нажмите «Загрузить» — откроется экран прайса со строками.

### Разобрать строки

1. Конфликтные строки: выберите товар из списка кандидатов.
2. Любую строку можно привязать вручную: «Выбрать товар» (или «Сменить товар») открывает подбор из номенклатуры. Артикул поставщика запоминается, в следующий раз строка найдётся сама.
3. Ненужные строки нажмите «Пропустить», вернуть — «Вернуть».
4. «Найти по названиям» ищет для ненайденных строк наши товары с таким же наименованием. Если таких несколько, товар не подставляется.
5. «Создать товары» создаёт товары для строк, которые так и остались ненайденными: наименование и единица берутся из файла, артикул поставщика сохраняется. Перед созданием программа спрашивает подтверждение и показывает количество.

### Применить прайс

1. Нажмите «Применить».
2. Проверьте дату и сводку «Было → Станет» по виду цен поставщика. Строки, у которых нельзя привести цену к базе вида цен (у товара не задана ставка НДС), показаны в предупреждении и не записываются.
3. Нажмите «Применить цены». Прайс получит статус «Применён» и станет только для чтения.

Товары, которых нет в прайсе, не меняются. Повторное применение с той же датой заменяет цену, записанную вручную на эту дату.

## Где используется цена поставщика

После «Применить» цены попадают в вид цен «Цены поставщика …» — он создаётся сам при первой загрузке прайса. Дальше эти цены подставляются автоматически:

- **В документы закупки** (заказ поставщику, поступление). Цена берётся по первому заданному: вид цен в шапке документа → вид цен договора → вид цен этого поставщика → «Закупочная».
- **В смету объекта.** Если в строке сметы указан поставщик, себестоимость строки подставляется из его цен на сегодня (см. [Сметы](../construction/estimates.md)).
- **В карточку товара.** В блоке «Номенклатура контрагента» — колонка «Цена» с ценой поставщика на сегодня.

Прежние цены не удаляются: вид цен хранит историю по датам, и документ берёт цену на свою дату.

## Права

Вкладка, загрузка, разбор и применение — владелец и администраторы. Исходный файл прайса тоже доступен только им. Участникам и гостям вкладка не показывается.

## Частые ошибки

- **«В файле нет строк данных для этого формата».** Проверьте «Первую строку данных» в формате: она могла оказаться ниже последней строки файла.
- **Все строки «Не найдено».** Артикулы поставщика у наших товаров ещё не заведены: воспользуйтесь «Найти по названиям» или «Создать товары». Артикулы можно добавить заранее на вкладке «Коды» контрагента.
- **Прайс уже применён, строки не меняются.** Применённый прайс закрыт для правки; загрузите новый файл.
