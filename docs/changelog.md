# Журнал доработок

Что и когда добавлено в FutureERP. Новые записи — сверху. Каждая доработка (задача TaskFlow, исправление, заметное
изменение) получает строку в день, когда попала в `main`: **модуль** — что изменилось для пользователя или разработчика,
в скобках номер задачи. Подробности — в `docs/architecture/*.md`, планах `docs/plans/` и статьях `docs/user/`.

Модули: Платформа, Проекты и задачи, CRM, Торговля, Склад, Производство, Услуги, Финансы, Транспорт, Объекты, Каталог,
Автоматизации, Настройки, Агенты и MCP, Аналитика, Справка, Деплой.

Записи до 2026-11-07 восстановлены по истории коммитов и сгруппированы по дням.

## 2026-11-07
- **Справка** — пункт «Документация» в меню «Помощь и материалы» открывает справку (раньше не реагировал на клик).
- **Агенты и MCP** — запись через MCP: задачи, комментарии, сделки, лиды, черновики документов (КП, заказ, счёт, заказ
  поставщику, поступление), проведение — только токену с правом «Проводить, оплачивать, удалять»; без этого права токен
  не удаляет, не проводит и не создаёт оплаты; лимит 120 запросов в минуту на токен; в ленте активности и карточке
  задачи — «через агента «название»» (1287).
- **Агенты и MCP** — MCP-сервер `/api/mcp` для Claude, Cursor и других агентов: поиск, карточки, документы, остатки,
  задачи и 8 отчётов с правами токена; адрес и команда подключения в окне выпущенного токена (1286).
- **Настройки** — раздел «Доступ для агентов»: токены от имени сотрудника (только чтение, разделы, срок), служебные
  сотрудники без входа по паролю, отзыв токена (1285).
- **Платформа** — разделы должностей проверяются на сервере: сотрудник со скрытым разделом не достанет его через API (1284).
- **Аналитика** — своя аналитика активности пользователей на Umami: открытия разделов, карточек и окон.
- **Производство** — параметрические изделия в плане производства и его потребностях.
