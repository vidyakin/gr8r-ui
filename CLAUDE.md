# gr8r-ui — правила для Claude

Главные документы: `docs/architecture.md` — оглавление предметных разделов в `docs/architecture/*.md`, и `README.md` (запуск, бэкенд, как добавить узел автоматизации). Читай только нужный раздел.

## Карта пакетов
Работаешь в пакете — сначала прочитай его `AGENTS.md` (устройство кода, куда класть новое, команды, частые ошибки), затем нужный `docs/architecture/<раздел>.md`.

| Пакет | Что внутри | Читать |
|---|---|---|
| `apps/web` | интерфейс: экраны, кэш TanStack Query, realtime, i18n | `apps/web/AGENTS.md` |
| `apps/api` | HTTP API на Hono, WebSocket, права и транзакция арендатора | `apps/api/AGENTS.md` |
| `apps/worker` | очередь jobs, outbox, автоматизации, PDF, биллинг, закрытие месяца | `apps/worker/AGENTS.md` |
| `packages/db` | схема Drizzle, миграции, RLS, доменные сервисы | `packages/db/AGENTS.md` |
| `packages/shared` | zod-схемы, типы, decimal, расчёты, узлы автоматизаций | `packages/shared/AGENTS.md` |

Задача на несколько пакетов (новая сущность от таблицы до экрана) — порядок `db` → `shared` → `api` → `web`, `AGENTS.md` каждого.

## Как работаем
- Отвечать пользователю по-русски. Комментарии в коде — на русском, коротко.
- Тексты UI — только через `t()` (`apps/web/src/i18n`): английский словарь `en/*` — источник ключей, русский перевод `ru/*` обязателен; даты и числа — через форматтеры `i18n/format.ts`. Подробности — `docs/architecture.md`, «Языки интерфейса». Демо-данные и печатные формы — по-русски, без перевода.
- Крупные задачи раздавать субагентам на Sonnet (`model: sonnet`, `isolation: worktree`), независимые — параллельно. Сводить ветки самому, проверять и пушить прямо в `main`, без PR.
- Экономить токены: промпты агентам короткие, со ссылкой на `docs/architecture.md`/`README.md` вместо пересказа; не гонять все тесты и не делать попиксельных сверок без нужды.
- Проверка при сведении: `bun install`, `bun run typecheck` (5 пакетов), тесты только по затронутому (`bun test <путь>`).
- Сообщения коммитов — на русском. Трейлер: `Co-Authored-By: Claude <модель> <noreply@anthropic.com>` (у агентов — их модель).

## Стек и структура
- Bun workspaces. `apps/web` — React 19 + TS + Vite + Tailwind v4 + Radix (shadcn-совместимо), TanStack Query, @xyflow/react. `apps/api` — Hono + WebSocket. `apps/worker` — очередь jobs/events, автоматизации, PDF. `packages/shared` — zod-схемы, типы, decimal, BOM, узлы автоматизаций. `packages/db` — Drizzle, миграции, RLS.
- UI-кит: `apps/web/src/components/ui` и `apps/web/src/components/gr8r` — переиспользовать, не дублировать.
- Мультитенантность через RLS по `workspace_id`; запросы API идут под `app_user`, DDL — только воркер (`DATABASE_URL_DDL`).

## Запуск
```bash
bun install && cp .env.example .env
docker compose up -d db   # или свой Postgres 16, адреса в .env
bun run db:reset && bun run dev
```
Демо: `demo@gr8r.dev` / `demo1234`, второй арендатор `bob@acme.test` / `bob12345`.

## Состояние и открытые вопросы
- Прогресс: статусы задач — TaskFlow (сессия 46 — услуги и CRM); что сделано по этапам — `docs/architecture/stages.md`; решения и «Фактическая реализация» каждой задачи — `docs/plans/2026-10-21-unf-*.md`.
- Отложено: почта и SMS с хранилищем секретов (1092), Яндекс.Доставка (1100, часть 2).
- Ждём от пользователя набор узлов автоматизаций.
- Варианты следующего шага: оплаты (касса и банк — кассовый факт для инвестпроектов и отчётов), файлы (S3) и печать с подписью, доступ к закрытым проектам в API, деплой на VPS и проверка Docker-сборки (в облаке не проверялась).
- Мелочи: сид закрывает текущий месяц (`closedThrough`), документы этой недели в демо не проводятся; демо-доставки назначены не курьерам; английские названия категорий состояний заказ-наряда и печатных форм; нет переименования видов номенклатуры; новые экраны не в палитре; объединить две шапки в плавающем окне задачи.
- Миграции: `drizzle-kit generate` нумерует на один меньше (нет 0028) и перезаписывает прошлый снапшот — вернуть снапшот из git, переименовать файл и тег в журнале.
