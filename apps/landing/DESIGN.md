# Альтернативный лендинг

Первый экран `/v2/` — по Figma Scrub, узел `944:2259`. Первый лендинг остаётся на `/`.

Третья версия `/v3/` использует ту же компоновку с компонентом `src/components/ui/gradient-wave.tsx` из вложения пользователя. Палитра по умолчанию — шесть чередующихся голубых `#38BDF8` и белых волн, noiseSpeed 0.00001, incline 0.5, noiseAmp 250, noiseFlow 5. Сохранены стеклянная рамка с блюром 8px, таймер и переключение модулей. На светлом фоне — тёмный текст и белая полупрозрачная оболочка. Версия `/v2/` сохраняет Silk.

Gradient Wave адаптирован к обычному CSS без установки Tailwind: исходные GLSL-формулы сохранены, массив активных цветов поддерживает все шесть слоёв, параметры деформации обновляют значения uniforms. Размер берётся из контейнера, DPR ограничен 2. При скрытой вкладке и reduced motion анимация останавливается; WebGL-ресурсы и обработчики освобождаются при размонтировании, потерянный контекст восстанавливается. Компонент загружается только для `/v3/`.

Палитра карточек: графит `#3f4246`, вторичный текст `#5d5b5b`, синий `#6889d7`, рамки `#b6d4f5`, белые карточки. Фон — Silk из 21st.dev Shader Builder на чистом WebGL1, палитра `#03120E → #0E7C5A → #7CE577 → #F4FFC7`. Исходный fragment shader хранится без изменений в `silk.frag`; packed uniforms соответствуют рецепту пользователя, время умножается на 0.42 (вдвое медленнее исходного рецепта), курсор отключён. Canvas расположен абсолютно за содержимым страницы, DPR ограничен 2, скрытая вкладка останавливает RAF, reduced motion оставляет статичный кадр. При недоступном WebGL — CSS-градиент, потерянный контекст восстанавливается. Заголовок — Helvetica Neue с системным Helvetica/Arial; точного шрифта Neue Haas в проекте нет. Внутри демо-экранов сохраняется шрифт продукта.

На широком экране слева сетка 3×3, описание и CTA, справа название продукта и экран модуля. На телефоне: заголовок, разделы, экран, описание продукта и CTA. Радиусы: оболочка 24px, карточки 20px, экран 16px.

Над Silk-фоном оболочка имеет затемнение `rgb(3 18 14 / 60%)` и backdrop blur 8px; заголовок, описание продукта и подпись CTA — `#F4FFC7`, акцент в описании — `#7CE577`. Это сохраняет контраст при движении светлых волн; карточки и демо-экраны остаются светлыми.

Раздел меняется по клику, стрелкам или каждые 9 секунд. Отсчёт виден в активной карточке; клик сбрасывает отсчёт. Есть общая пауза. Скрытая вкладка, уход первого экрана из видимости и reduced motion останавливают автопереключение. Тексты — в словаре лендинга.

Сетка разделов и масштабируемые демо-экраны не меняют размеры при переключении. CRM использует локальный экспорт из Figma; основные модули — готовые сцены первого лендинга. Продажи, логистика, зарплата и процессы показывают статические демо-данные в существующей оболочке.
