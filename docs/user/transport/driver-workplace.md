# Место водителя

## Для чего раздел

Здесь водитель видит свои рейсы на сегодня и отмечает выполнение точек.

## Что на экране

Точки показаны по порядку. Можно открыть адрес в навигаторе, отметить прибытие, доставку или отказ, приложить фото и подпись получателя. Для доставки доступны приём наличных, ссылка на онлайн-оплату и возврат выбранного количества товаров.

## Типовые действия

1. Откройте назначенный рейс и точку. Нажмите «Открыть навигатор», чтобы построить маршрут.
2. По прибытии нажмите «Прибыл». При вручении добавьте фото и подпись и нажмите «Доставил»; при отказе нажмите «Отказ».
3. Для наличных введите сумму и нажмите «Принять наличные». Чтобы получить ссылку, нажмите «Создать ссылку на оплату».
4. Для частичного отказа укажите количество по нужным строкам и нажмите «Вернуть выбранные товары». Возврат доступен по проведённой реализации.
5. Чтобы открыть приложение с домашнего экрана телефона, выберите установку в меню браузера.

## Права

Водитель видит назначенные ему рейсы. Для записи нужна роль участника или выше и включённый модуль транспорта.

## Частые ошибки

Если связи нет, отметки, наличные оплаты и возвраты ожидают отправки на устройстве. После восстановления связи оставьте страницу открытой до отправки. При ошибке проверьте данные и нажмите «Повторить отправку»; если операция ошибочна, её можно удалить из очереди. Открыть приложение после полного закрытия нужно при наличии связи. Онлайн-ссылка требует подключённой ЮKassa.
