# Чаты

## Для чего раздел

Раздел «Чаты» объединяет рабочие переписки внутри команды и внешние диалоги с заказчиками в одном окне. Каждое сообщение автоматически переводится на личный язык получателя, поэтому сотрудники и клиенты из разных стран могут писать на родном языке без ручного перевода.

## Что на экране

### Список чатов

- **Поиск и кнопка «Новый чат»** — быстрая фильтрация диалогов по названию и создание внутреннего или гостевого чата.
- **Список диалогов** — карточки чатов с названием, последним сообщением, временем обновления и отметкой внешнего (гостевого) диалога.

### Окно переписки

- **Шапка чата** — название диалога, список участников и управление публичной ссылкой для внешнего заказчика.
- **Лента сообщений** — показывает текст на вашем личном языке (из настроек профиля `users.locale`). Под переведённым сообщением доступна кнопка «Оригинал» для просмотра исходного текста; пока перевод готовится, отображается статус «Переводится…».
- **Поле ввода** — отправка по `Enter`, перенос строки по `Shift+Enter`.

### Гостевой чат по ссылке (`/c/:token`)

- **Открывается без регистрации** — заказчик переходит по выданной ссылке `/c/:token` в любом браузере на телефоне или компьютере.
- **Выбор языка клиента** — в шапке гостевой страницы клиент выбирает удобный язык; вся лента и интерфейс перестраиваются под выбранный язык, а ответы клиента автоматически переводятся для команды.
- **Имя гостя** — если имя не задано заранее, клиент может указать его в поле «Ваше имя» прямо в шапке чата.

## Типовые действия

### Создать внутренний чат с автопереводом

1. Откройте «Чаты» в левом меню и нажмите «Новый чат».
2. Укажите название диалога и выберите участников команды.
3. Пишите сообщения на своём языке — каждый участник увидит перевод на язык, выбранный в его личных настройках (`users.locale`), и при необходимости сможет раскрыть «Оригинал».

### Пригласить внешнего заказчика по ссылке

1. Откройте нужный чат (или создайте новый для клиента) и скопируйте публичную ссылку вида `/c/:token`.
2. Отправьте ссылку заказчику удобным способом (по почте или в мессенджере).
3. Заказчик открывает страницу без входа в систему, выбирает свой язык в шапке и сразу ведёт переписку с вашей командой.

## Права

Внутренние чаты доступны участникам воркспейса, добавленным в диалог. Создавать и управлять гостевыми ссылками `/c/:token` могут участники с правами не ниже сотрудника; внешний заказчик по ссылке видит только сообщения конкретного чата и не получает доступа к другим разделам системы.

## Частые ошибки

- **Сообщение отображается без перевода.** Проверьте, что в личных настройках выбран нужный язык интерфейса (`users.locale`), а у сообщения не стоит статус «Переводится…» (перевод появляется автоматически через несколько секунд).
- **Заказчик видит экран «Чат недоступен» по ссылке `/c/:token`.** Ссылка могла быть отозвана или скопирована не полностью — создайте новую ссылку в настройках чата и отправьте её клиенту повторно.
